# AI Voice-Controlled Autonomous Car 🚗

## Project Overview
An intelligent autonomous car project combining Artificial Intelligence and Embedded Systems.

The project explores voice-based interaction and intelligent vehicle control using embedded hardware and AI technologies.

## Technologies Used
- ESP32-CAM
- Python
- PyTorch
- Motor Driver

## Main Objectives
- Explore AI-based voice recognition.
- Integrate embedded hardware with intelligent control.
- Translate recognized voice commands into vehicle actions.

## Key Areas
- Embedded Systems
- Artificial Intelligence
- Voice Recognition
- Motor Control
